Notes on the Riemann-Lebesgue lemma

The Riemann-Lebesgue lemma states that the Fourier transform of an integrable function vanishes at infinity, i.e. $|\mathcal{F}[f](x)| \rightarrow 0$, for $x \rightarrow \pm\infty$, with $$ \mathcal{F}[f](x) := \int_{\mathbb{R}}f(w)e^{ixw} \mathrm{d}w, \quad f \in L^{1}(\mathbb{R}). $$ In fact, the Fourier transform is a bounded linear operator $\mathcal{F}:L^{1}(\mathbb{R}^{d}, \mathbb{K}) \rightarrow C_0(\mathbb{R}^{d}, \mathbb{K})$.

While the rate of decay is arbitrarily slow in general [1], the convergence is faster if one assumes additional smoothness on the function $f$, see for instance [2, Table 3.1]. Limits for arbitrary bounded functions

If the trigonometric function $f$ is integrated against is positive, the limit of the integral cannot be zero anymore. However, several nice generalisations of the Riemann-Lebesgue lemma, which can be found in [3], may still be applicable. Suppose that $f \in L^{1}(\mathbb{R})$ and $\beta \in L^\infty (\mathbb{R})$ is symmetric. Then, we have $$ \lim_{\lambda \rightarrow \infty} \int_{\mathbb{R}}f(x)\beta(\lambda x) \mathrm{d}x = \left(\int_{\mathbb{R}}f(x)\mathrm{d}x \right)\left(\lim_{T \rightarrow \infty} \frac{1}{T} \int_{0}^{T} \beta(x) \mathrm{d}x\right), $$ provided that the latter mean value of the function exists. For a generalisation of this result to arbitrary dimensions see [3, Theorem 4]. If the function $\beta$ is not symmetric, as in the next animation, one can define $\beta_{\pm}(x)=\beta(\pm x)$ when $x \geq 0$, resulting in the convergence $$ \begin{align} & \lim_{\lambda \rightarrow \infty} \int_{\mathbb{R}}f(x)\beta(\lambda x) \mathrm{d}x \\ & = \left(\int_{0}^{\infty}f(x)\mathrm{d}x \right)\left(\lim_{T \rightarrow \infty} \frac{1}{T} \int_{0}^{T} \beta_{+}(x) \mathrm{d}x \right) + \left(\int_{-\infty}^{0}f(x)\mathrm{d}x \right)\left(\lim_{T \rightarrow \infty} \frac{1}{T} \int_{0}^{T} \beta_{-}(x) \mathrm{d}x \right). \end{align} $$ Remember that $(L^{1}(\mathbb{R}))^{*} \equiv L^{\infty}(\mathbb{R})$. Thus, we can interpret $\beta(\lambda \cdot)$ as an element of the dual space, which converges in weak* to the element $m_{+}\mathbf{1}_{(0,\infty)}+m_{-}\mathbf{1}_{(-\infty,0)}$ as $\lambda \rightarrow \infty$.
